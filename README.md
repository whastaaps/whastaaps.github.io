# WA Hanapha

A web-based platform for collecting links, groups, videos, and live streaming content with a lightweight and mobile-friendly interface.

## Website

- Main: https://wa.hanapha.com/
- Chat: https://wa.hanapha.com/chat/
- Group: https://wa.hanapha.com/group/
- Video: https://wa.hanapha.com/video/
- Live Video: https://wa.hanapha.com/video/live/
- Link Collection: https://wa.hanapha.com/link/

---

# Features

## Home
Main landing page with quick navigation to all available categories.

## Group
Public group collections organized by categories:
- Entertainment
- Community
- Business
- Gaming
- Viral
- Lifestyle

## Video
Collection of short and trending videos.

## Live
Live streaming page for real-time content and broadcasts.

## Link
Directory of popular and recommended links.
